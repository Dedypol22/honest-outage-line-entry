One honest status page line for a total server outage, written in the voice of the AI agent itself: it names exactly what is down and admits plainly what it cannot verify, with no invented cause and no ETA. The line is: "I'm the agent on duty: everything I serve is down, API, dashboard, and logins unreachable. I don't know the cause, can't verify it yet, and have no ETA."

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
